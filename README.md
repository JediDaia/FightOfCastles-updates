# Fight of Castles — загрузки для macOS

[**Скачать лаунчер для macOS**](https://github.com/JediDaia/FightOfCastles-updates/releases/download/launcher-v1.1.0/FightOfCastlesLauncher-macOS.zip)

macOS 13 и новее; сборка содержит Apple Silicon и Intel. Проверена на Apple Silicon, проверка на Intel ещё предстоит.

1. Скачайте ZIP, распакуйте и перенесите **Fight of Castles Launcher.app** в «Программы».
2. Откройте лаунчер, выберите **Alpha** и дождитесь установки игры.
3. Нажмите **Играть**. После публикации следующих версий лаунчер получает обновления при открытии или по кнопке проверки.

Лаунчер проверяет Ed25519-подпись выпуска и SHA-256 каждого блока. Проверенные блоки переиспользуются; сохраняется предыдущая версия для отката. Обновление устанавливается после закрытия игры.

## Первый запуск alpha

Эта тестовая alpha подписана ad-hoc, без Apple Developer ID и notarization. macOS может потребовать разрешить первое открытие через **Системные настройки → Конфиденциальность и безопасность → Всё равно открыть**. Не отключайте защиту macOS целиком. Контрольная сумма ZIP размещена рядом с файлом в релизе лаунчера.

## Что хранится здесь

Только готовые бинарные сборки, подписанные манифесты и блоки обновлений. Игровые исходники и история разработки хранятся отдельно в приватном репозитории. Игрокам не нужны GitHub-токены, исходники или редактор Godot.

Служебные prerelease `blobs-0`…`blobs-f` хранят проверяемые блоки; `channels` содержит указатели alpha/stable. Их скачивать вручную не нужно. Пользуйтесь ссылкой на лаунчер выше.

Лаунчер и игра — разные приложения. Первый общий лаунчер устанавливается один раз; дальнейшие игровые обновления получает сам. Эта первая раздача предназначена для alpha-тестирования на macOS.
